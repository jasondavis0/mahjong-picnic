# Mahjong Picnic

An ad-free mahjong tile-matching game for phone and iPad. Tap free tiles to send them to a 4-slot tray; two matching tiles in the tray clear. Endless levels that keep getting harder.

- Game source: `mahjong-picnic.html`
- Build the installable web app into `docs/` (served by GitHub Pages): `./build.sh`
